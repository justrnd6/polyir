Metal: where the time goes
find the GPU                              28 ms   once per program
compile the kernel                         1 ms   once per kernel
make 2 buffers, fill one with 4 MiB        0 ms   once per buffer
launch for 1 element, and wait           206 us   every launch
launch for 1,048,576 elements, wait      220 us   every launch
the CPU reads the 4 MiB of results         2 ms   no copy: same memory
